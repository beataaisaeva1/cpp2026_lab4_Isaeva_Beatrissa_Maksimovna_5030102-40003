# Арканоид
Вверху поля множество прямоугольных блоков. Внизу горизонтально перемещается каретка. По полю летает «мяч», отражаясь от стен, блоков и каретки. Если мяч попадает вниз (мимо каретки) начисляются отрицательные очки /уменьшается каретка/увеличивается число поражений. Блоки бывают разных типов:
1) Неразрушаемые. От них мяч просто отскакивает.
2) Блоки могут быть со спрятанными бонусами: при попадании вертикально вниз падает бонус
3) Блоки, увеличивающие скорость шарика при столкновении
4) Блоки имеют уровень здоровья = число попаданий, чтобы блок исчез. За каждое попадание +1 очко игроку, -1 очко здоровья блоку.
5) Бонусы: меняют размер каретки, меняют скорость шарика, меняют прилипание шарика к каретке.
6) Бонус: одноразовое дно для шарика – можно один раз пропустить, дно сработает как каретка, и исчезнет.
7) Бонус: шарик в произвольный момент меняет траекторию.
8) Бонус: появляется двигающий блок, не задевающий при движении остальные блоки (надо проверять коллизии), и живущий до 3 ударов
9) Бонус: появляется второй шарик, способный оттолкнуться и от первого, и от блоков/стенок
Для сдачи: 1-6 + 1 на выбор из 7-9

# Среда разработки
Visual Studio 2022

# Как скачать SFML через GitHub
1. Открыть GitHub:
https://github.com/SFML/SFML.
2. Справа открыть раздел Releases.
3. Найти релиз 2.6.2.
4. Раскрыть пункт Assets.
5. Скачать архив:
SFML-2.6.2-windows-vc17-64-bit.zip.
Данная версия подходит для Visual Studio 2022 (64-bit).
6. После скачивания распаковать архив, например, в папку:
C:\SFML\SFML-2.6.2.
Внутри должны находиться папки:
include  
lib  
bin

# Как запустить проект
В Visual Studio 2022 создать новый проект:
Console App C++.
После создания проекта открыть файл с кодом и вставить туда содержимое main.cpp.

Открыть свойства проекта:
Проект - Свойства.
Сверху выбрать:
Конфигурация: Все конфигурации.  
Платформа: x64.

Слева открыть:
C/C++ - Общие.
Справа найти:
Дополнительные каталоги включаемых файлов.
Добавить путь:
C:\SFML\SFML-2.6.2\include.
Слева открыть:
Компоновщик - Общие.
Справа найти:
Дополнительные каталоги библиотек.
Добавить путь:
C:\SFML\SFML-2.6.2\lib.
Слева открыть:
Компоновщик - Ввод.
Справа найти:
Дополнительные зависимости.
Добавить:
sfml-graphics.lib  
sfml-window.lib  
sfml-system.lib
После этого нажать:
Применить - ОК.

Открыть папку:
C:\SFML\SFML-2.6.2\bin.
Скопировать файлы:
sfml-graphics-2.dll  
sfml-window-2.dll  
sfml-system-2.dll
И вставить их в папку проекта рядом с .exe файлом.
